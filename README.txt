DIMAT — DEMO DE SITIO WEB

ARCHIVOS
- index.html: estructura de la página
- styles.css: diseño y adaptación a celulares
- script.js: catálogo, filtros, botones de contacto y banner de cookies

CÓMO VER LA DEMO EN TU PC
1. Descargá y descomprimí el archivo ZIP.
2. Abrí la carpeta dimat-demo.
3. Hacé doble clic en index.html para abrirlo en tu navegador.
4. Necesitás internet para que carguen las fuentes y las imágenes externas.

IMPORTANTE
- Los precios son ficticios y se identifican como demostración.
- Las direcciones y el contenido legal deben confirmarse con DIMAT.
- El número de WhatsApp está sin configurar. Para habilitar los enlaces, abrí script.js y reemplazá la línea WHATSAPP_NUMBER = '' por el número oficial en formato internacional, sin + ni espacios.
- El banner de cookies guarda preferencias únicamente en el navegador local. NO envía datos a un servidor y NO registra personas identificadas.
- Las páginas legales son borradores de demostración, no asesoramiento legal.
- Esta versión es una demo frontend estática. No incluye un panel administrativo real ni base de datos de consentimientos.

PUBLICAR GRATIS
Podés subir estos archivos a un repositorio de GitHub y activar GitHub Pages en Settings > Pages. Elegí Deploy from a branch, seleccioná la rama main y la carpeta /(root), y guardá. La URL pública aparecerá en esa misma sección. No subas datos personales reales ni claves secretas.
